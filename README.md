Проект: Mesto (Interactive Page)
Mesto — это интерактивная страница, созданная в рамках учебной программы Яндекса и СГУ. Проект представляет собой сервис, где пользователи могут делиться фотографиями интересных мест, удалять их и отмечать понравившиеся снимки лайками.

---

Основные возможности:
Редактирование профиля пользователя (имя, занятие, аватар).
Добавление новых карточек с местами (название и ссылка на изображение).
Функциональность лайков и удаления карточек.
Валидация форм в режиме реального времени.

---

Инструкция по развертыванию

Требования
Для работы с проектом вам понадобится установленный Node.js и менеджер пакетов (npm).

Клонируйте репозиторий:
git clone https://github.com/ваш-логин/mesto.git

Установите зависимости:
npm install

Запустите проект в режиме разработки:
npm run dev

Соберите проект (Production):
npm run build

Команда для публикации:
npm run deploy

Для того чтобы проект был доступен для онлайн-просмотра, используется GitHub Pages.
