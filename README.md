## Проект: Mesto (интерактивная страница)

Mesto — интерактивная страница, созданная в рамках учебной программы Яндекса и СГУ. Это сервис, где пользователи делятся фотографиями интересных мест, удаляют карточки и отмечают понравившиеся снимки лайками.

В работе использовались HTML, CSS, JavaScript (модули), сборка на Vite, запросы к REST API (Fetch), Git и GitHub Pages для публикации.

---

## Основные возможности

- Редактирование профиля (имя, описание, аватар).
- Добавление карточек мест (название и ссылка на изображение).
- Лайки и удаление своих карточек.
- Валидация форм в реальном времени.

## Локальный запуск и сборка

**Требования:** установленные Node.js и npm.

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/F3nd1uwu/mesto-ad.git
cd mesto-ad
npm install
```

Команды:

| Действие | Команда |
|----------|---------|
| Режим разработки | `npm run dev` |
| Сборка | `npm run build` |
| Просмотр сборки | `npm run preview` |
| Публикация на GitHub Pages | `npm run deploy` |

Для онлайн-просмотра используется GitHub Pages (скрипт `deploy` собирает проект и выкладывает папку `dist`).
